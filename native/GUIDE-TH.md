# คู่มือติดตั้ง Maalot แอป Android แบบละเอียด (ไม่ต้องมี Mac หรือ Android Studio)

ใช้เฉพาะเบราว์เซอร์และมือถือ Android ทำได้ทั้งหมด

## ขั้นที่ 0: เตรียมโค้ดให้อยู่บน main
ไฟล์สร้างแอป (`.github/workflows/android.yml`) ต้องอยู่ในบรานช์ `main` ก่อน ปุ่มสร้างถึงจะโผล่ในหน้า Actions ให้เปิด PR แล้ว Merge ก่อน

## ขั้นที่ 1: สั่งสร้างแอป
1. เปิดหน้ารีโพบน GitHub (`github.com/Peterlai26/Maalot`) ด้วยคอมหรือมือถือ ล็อกอินบัญชีที่เป็นเจ้าของ
2. แตะแท็บ **Actions** ด้านบน
3. แถบซ้ายเลือก **Build Android app** (ถ้าบนมือถือให้แตะรายการ workflow ใต้หัวข้อ "All workflows")
4. แตะปุ่ม **Run workflow** (ด้านขวา) เลือกบรานช์ `main` แล้วกด **Run workflow** สีเขียว
5. รอ 5–10 นาที รายการด้านบนจะเปลี่ยนจากสีเหลือง (กำลังทำ) เป็นเครื่องหมายถูกสีเขียว (สำเร็จ)

ถ้าเป็นเครื่องหมาย ✕ สีแดง ให้แตะรายการนั้น แตะงาน **apk** แล้วดูว่าขั้นไหนแดง คัดลอกข้อความท้ายล็อกส่งให้ผมแก้ได้เลย

## ขั้นที่ 2: โหลดไฟล์ติดตั้งลงมือถือ
1. บนมือถือ Android เปิดหน้ารีโพ แตะ **Releases** (แถบขวาของหน้าแรก) แล้วเลือกรุ่น **Maalot Android (debug build)**
2. แตะไฟล์ **maalot.apk** เพื่อดาวน์โหลด (ถ้าเบราว์เซอร์เตือนว่าไฟล์อาจเป็นอันตราย แตะ "ดาวน์โหลดต่อ")
3. ถ้ารีโพเป็นส่วนตัว (private) ต้องล็อกอิน GitHub บนมือถือก่อนถึงจะเห็นไฟล์ หรือใช้วิธีสำรอง: ที่หน้าผลการรัน Actions เลื่อนลงล่างสุดหัวข้อ Artifacts แตะ **maalot-debug-apk** ได้ไฟล์ zip แล้วแตกไฟล์ด้วยแอป Files แล้วจะเจอ `app-debug.apk`

## ขั้นที่ 3: ติดตั้ง
1. เปิดไฟล์ `maalot.apk` จากการแจ้งเตือนดาวน์โหลดหรือจากแอป Files > Downloads
2. ถ้าขึ้น "เพื่อความปลอดภัย โทรศัพท์ไม่อนุญาตให้ติดตั้งแอปที่ไม่รู้จักจากแหล่งนี้" แตะ **การตั้งค่า** แล้วเปิด **อนุญาตจากแหล่งนี้** (แหล่งคือเบราว์เซอร์ที่ใช้โหลด เช่น Chrome หรือ Brave) แล้วกดย้อนกลับ
3. แตะ **ติดตั้ง** ถ้า Google Play Protect ขึ้นเตือน แตะ **ติดตั้งต่อไป** (เพราะเป็นแอปทดสอบที่ยังไม่ผ่านร้าน)
4. ถ้าขึ้น "ไม่ได้ติดตั้งแอป" ให้ลบแอป Maalot เวอร์ชันเก่าที่เคยลงจากไฟล์อื่นก่อนแล้วลองใหม่

## ขั้นที่ 4: ตั้งค่าครั้งแรก
1. เปิดแอป **Maalot** ล็อกอินด้วยบัญชีเดิม (ต้อง deploy เซิร์ฟเวอร์ `worker` รุ่นล่าสุดก่อน ไม่เช่นนั้นล็อกอินไม่ผ่าน)
2. ไปที่ **ทุกโหมด → เดินวันนี้**
3. แตะ **เริ่มนับก้าวด้วย GPS** → ยืนยันในหน้าต่างของแอป → เลือก **ขณะใช้แอป** หรือ **ตลอดเวลา** ในหน้าขอสิทธิ์ตำแหน่ง (แนะนำ **อนุญาตตลอดเวลา** ถ้าอยากให้นับตอนปิดจอ)
4. อนุญาตการแจ้งเตือนเมื่อระบบถาม (Android 13 ขึ้นไป) เพราะขณะนับจะมีแจ้งเตือนค้าง
5. เปิดสวิตช์ **ก้าวจากแอปสุขภาพของเครื่อง** แล้วอนุญาตการอ่านจำนวนก้าวใน Health Connect (Android 14 ขึ้นไปมีในเครื่อง รุ่นต่ำกว่าต้องติดตั้ง "Health Connect by Android" จาก Play Store ก่อน)

## ขั้นที่ 5: กันระบบฆ่าแอปตอนนับ (สำคัญกับมือถือบางยี่ห้อ)
ไปที่ ตั้งค่า > แอป > Maalot > แบตเตอรี่ แล้วเลือก **ไม่จำกัด** (Unrestricted) ยี่ห้อ Xiaomi, Oppo, Vivo, Huawei, Samsung ให้เปิด "เริ่มอัตโนมัติ" หรือปิดการประหยัดแบตของแอปนี้ด้วย ไม่งั้นระบบอาจปิดการนับเมื่อล็อกจอนานๆ

## เมื่อแก้เว็บแอปแล้วอยากอัปเดตแอป
ทุกครั้งที่โค้ดเว็บเปลี่ยน ให้ทำขั้นที่ 1–3 ใหม่ (ติดตั้งทับของเดิมได้เลย ข้อมูลในแอปไม่หาย)

## iPhone ไม่มี Mac ทำอย่างไร
- ตอนนี้ใช้ **เว็บแอป (PWA)** ได้: เปิด Maalot ใน Safari แล้วแตะแชร์ → เพิ่มลงหน้าจอโฮม จะได้แจ้งเตือนและใช้งานได้ แต่ GPS นับได้เฉพาะตอนเปิดหน้าจอแอปค้าง และอ่านก้าวจาก Apple Health ไม่ได้
- ถ้าอยากได้แอปเนทีฟบน iPhone โดยไม่มี Mac ต้องใช้เครื่อง Mac บนคลาวด์ (เช่น macOS runner ของ GitHub Actions) ร่วมกับบัญชี Apple Developer (99 ดอลลาร์ต่อปี) และส่งผ่าน TestFlight ซึ่งยังไม่ได้ตั้งค่าไว้ในโปรเจกต์นี้ ถ้าต้องการให้ทำ บอกได้ ผมจะเขียนขั้นตอนเพิ่ม

## ปัญหาที่พบบ่อย
| อาการ | วิธีแก้ |
|---|---|
| ปุ่ม Run workflow ไม่ขึ้น | ยังไม่ได้ Merge เข้า main หรือไม่ได้ล็อกอิน GitHub |
| ล็อกอินในแอปไม่ผ่าน | ยังไม่ได้ deploy เซิร์ฟเวอร์ (`npx wrangler deploy` ในโฟลเดอร์ `worker`) |
| ก้าวไม่ขึ้นตอนปิดจอ | ยังไม่ได้เลือกสิทธิ์ตำแหน่ง "ตลอดเวลา" หรือแบตเตอรี่ยังจำกัดแอป (ขั้นที่ 5) |
| ก้าวจาก Health Connect เป็น 0 | ยังไม่มีแอปไหนเขียนก้าวลง Health Connect ให้เปิดการบันทึกก้าวของเครื่องหรือแอปนับก้าวอื่นก่อน |
| แอปไม่เด้งเตือนตอนปิดแอป | ข้อจำกัดของรุ่นนี้ เตือนได้เฉพาะตอนเปิดแอปอยู่ |
